**Summary of the public version (16.7)**

**General**
- Fork of the OGame bot TBot with a web UI, the Go helper `ogamed` and a possible config split into separate files.
- One shared instance bar on every page, a "Hide data" switch for screenshots, Discord and Telegram notifications.
- update check on the Start page.
-moveable / resizeable Info Tiles on Startpage

**Expeditions**
- Ships can be spread evenly over all free slots (`SplitAllToSlots`, useful for small players).
- Slots per start moon with priorities, minimum primary ships, return time for the sleep phase.
- Supply of the expedition moons with ships and deuterium.
- Jumpgate usable to jump expedition Ship founds to a base
  
**Farm**
- AutoFarm also attacks defended targets, with an escort fleet and combat simulation.
- Limits and protection: alliance whitelist, deuterium guard, minimum loot, cap on defence points.
- Combat sim as a tab under Fleet&Farm: three calculators compared, battle log with export (CSV/JSON) and reset.
- use of your prefered Compatsim

**Build and research**
- All build and research steps in one plan, ordered by price, with the lifeform discount on Astrophysics.
- Separate queues for mines, lifeform buildings, lifeform research and research.
- New colonies start with mines and storage they can afford, AutoDefence in the same area.

**Other**
- Rewards and boosters on one page: tasks, boosters, daily offer, directives, asteroid event.
- Sleep and security: Defender, GhostSleep (run Expedition in sleep reduced Defender activity) and SleepMode .
- The web UI login is on or off depending on the address it is reachable from. Can be disabled.

**UI**
- Fully changed UI
